\# HR Analytics Dashboard



\## Overview

This project is an interactive HR Analytics Dashboard developed using Power BI to analyze employee data and provide valuable workforce insights. The dashboard helps organizations understand employee trends, attrition patterns, and overall workforce performance.



\## Features

\- Employee Attrition Analysis

\- Department-wise Employee Distribution

\- Gender-wise Analysis

\- Performance Tracking

\- Interactive Filters and Slicers

\- Workforce Insights and Reporting



\## Tools \& Technologies Used

\- Power BI

\- Microsoft Excel

\- Power Query

\- DAX (Data Analysis Expressions)



\## Objectives

\- Monitor employee attrition rates

\- Analyze workforce demographics

\- Track employee performance metrics

\- Support HR decision-making through data visualization
